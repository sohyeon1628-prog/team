## 📅 2026-10-12 (오늘) 작업 로그

### 1. 팩트체크 드로어 (`FactCheckDrawer.jsx`)
- **상단 타이틀 이모지 제거**:
  - 팩트체크 사이드 드로어 상단 헤더의 방패(Shield) 아이콘을 제거하여 깔끔한 타이포그래피 유지.

### 2. 사진 첨부 사이드 드로어 (`PhotoSideDrawer.jsx`)
- **헤더 이모지 정리**: 상단 '사진 첨부' 타이틀 좌측의 불필요한 이모지 제거.
- **사진 카드 호버 인터랙션 개선**:
  - 마우스 호버 시 카드가 흔들리지 않고 안정적으로 고정되도록 CSS 레이아웃 조정.
  - 호버 시 나타나는 플로팅 액션 바를 투명감 있는 글래스모피즘 스타일의 **[이미지 첨부하기]** 및 **[편집하기]** 버튼으로 개편.
  - 하단에 중복 배치되어 있던 사진 첨부/편집 버튼 일괄 정리.
- **플로팅 텍스트바 연동**:
  - 본문 텍스트 드래그 시 나타나는 서식 툴바의 '이미지' 버튼 클릭 시 우측 사진 첨부 드로어가 즉시 펼쳐지도록 연동.

### 3. 본문 사진 첨부 및 커서/스크롤 고도화 (`ArticleWriter.jsx`)
- **[이미지 첨부하기] 원클릭 본문 연동**:
  - 사이드 드로어의 [이미지 첨부하기] 버튼 클릭 시 `onMouseDown` 기본 이벤트 차단(`e.preventDefault()`)을 통해 본문 커서(Selection Range)가 풀리는 현상 해결.
- **커서 위치 및 텍스트 끝 지점 정확한 삽입**:
  - 에디터 내 커서 위치(`lastCaretRangeRef`)를 실시간으로 추적·저장.
  - 커서가 위치해 있는 지점에 사진과 캡션 블록(`<figure>...<figcaption>...</figcaption></figure>`) 즉시 삽입.
  - 커서가 지정되지 않았거나 외부 상태인 경우 현재 작성된 본문 텍스트가 끝나는 지점에 안전하게 삽입.
- **부드러운 스크롤 애니메이션**:
  - 본문에 사진 블록이 삽입된 직후 해당 사진 위치로 자동 이동(`scrollIntoView({ behavior: "smooth", block: "center" })`).
- **본문 내 사진 드래그 앤 드롭 이동**:
  - 첨부된 사진 블록을 마우스로 드래그하여 텍스트가 끝나는 문단/문장 지점마다 자유롭게 이동할 수 있는 인터랙션 지원.
- **빌드 검증**: `npm run build` 프로덕션 빌드 무결성 통과 (오류 0건).
